# 🌱 Khety | Growing Together

Khety is a modern agricultural services platform that connects farmers with experienced agricultural service providers.

## About the Project

Khety helps farmers discover nearby agricultural service providers who have the required skills and equipment to complete farming tasks.

Farmers can request services, receive quotations, track job progress and confirm completed work.

The platform also provides AI-powered crop analysis to help farmers understand possible crop health issues.

## Key Features

- Farmer and service provider accounts
- Nearby agricultural service discovery
- Provider profiles and equipment details
- Service requests and quotations
- Job tracking and completion
- Payments and reviews
- AI crop analysis
- Multilingual support: English, Gujarati and Hindi
